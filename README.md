# Копия сайта «сТАТУс»

Статическая копия публичной страницы [statustattoo.ru](https://statustattoo.ru/). Оформление, фотографии и интерфейс сохранены; контакты и ссылки исходной студии оставлены без изменений.

Сборка и установка зависимостей не нужны. Для локального просмотра выполните `python3 -m http.server 8080` и откройте http://localhost:8080/.

Для публикации в GitHub Pages откройте **Settings → Pages**, выберите **Deploy from a branch**, затем ветку **main** и каталог **/(root)**.
